STEP 0 -- resize_window's colorScheme param does NOT flip THIS app's theme:
  resize_window({width:1280,height:800,colorScheme:"dark"}) -> OS-level
  prefers-color-scheme became dark (matchMedia confirmed true), but the app kept
  rendering light (bodyBg rgb(255,255,255), bodyColor rgb(3,7,18)) because it reads
  an explicit `theme` cookie (found `theme=light` already set) that overrides the OS
  preference rather than following prefers-color-scheme automatically. This is worth
  a "nit" flag: the plan's suggested mechanism for toggling theme in this test
  ("resize_window colorScheme") does not actually exercise this app's dark mode --
  a real device/user would need the app's own theme toggle (not tested here; out of
  this browser-visual pass's scope, share pages carry no visible theme switch UI in
  the DOM). Worked around it by setting the `theme` cookie directly (document.cookie)
  and reloading, which IS how the app's own toggle would behave client-side.

Data365 · ko'chirish

Ilovani sizning serveringizga ko'chiramiz

Bu sahifa siz uchun. Texnik ish bizda — sizdan uchta narsa va bir nechta tasdiq kerak, xolos. Hech qayerga shoshilmang: har bir qadamni bajarib bo'lgach, belgilab qo'ying.

Avval eng muhimi. Hozirgi serverdagi hech narsa o'chirilmaydi. Yangi joyda har bir yozuv ochilayotgani bittalab isbotlanmaguncha, eski server ham, eski videolar ham joyida turadi. O'chirish kerak bo'lganda sizdan alohida so'raymiz.
1

Serverni tekshiramiz

Serveringizni hali ko'rmaganmiz. Avval uni o'qib chiqamiz — quvvati yetadimi, joy bormi, boshqa nima ishlayapti. Shu javoblarsiz keyingi qadamni to'g'ri rejalashtirib bo'lmaydi.

Biz bilan birga 01-server-check.sh faylini oldingiz. Uni serverga qo'ying va quyidagini bajaring: 

bash 01-server-check.sh
Bu skript serverga hech narsa qilmaydi. Hech narsa o'rnatmaydi, o'chirmaydi va to'xtatmaydi — u faqat ma'lumot o'qiydi va ekranga hisobot chiqaradi. Ishonch hosil qilish uchun faylni oldin oddiy matn ko'rinishida o'zingiz o'qib chiqishingiz mumkin, biz buni tavsiya qilamiz.

Oxirida «NUSXALASH SHU YERDAN BOSHLANADI» deb yozilgan qismni nusxalab bizga yuboring.

2

Videolar uchun ombor ochasiz (Cloudflare R2)

Videolar serverda emas, alohida omborda saqlanadi — server yiqilsa ham videolar tirik qoladi. Ombor sizning nomingizda bo'lishi kerak, aks holda u bizning hisobimizga bog'liq qolaveradi.

  1. cloudflare.com — ro'yxatdan o'ting (bepul).
  2. Chap menyudan R2 bo'limini oching.
  3. Create bucket → nomi: ustoz-videos
  4. So'ng Manage API tokens → Create API token → ruxsat: Object Read & Write.
  5. Chiqqan ikkita kalitni (Access Key ID va Secret Access Key) saqlab qo'ying — Secret faqat bir marta ko'rsatiladi.
Kalitlarni oddiy xabarda yubormang. Parol menejeri orqali yoki biz aytadigan xavfsiz usulda yuboring. Kalit — bu eshikning kaliti.
3

Sun'iy intellekt kaliti (Gemini)

Uchrashuvlarni matnga aylantirish va qisqacha xulosa yozish shu kalit orqali ishlaydi. Kalit sizniki bo'lgach, bu xarajat ham to'g'ridan-to'g'ri sizga o'tadi va biz orada turmaymiz.

  1. aistudio.google.com/app/apikey manziliga kiring.
  2. Create API key tugmasini bosing.
  3. Chiqqan kalitni saqlang.

4

Serverga kirish huquqi

Ilovani o'rnatish uchun serverga bir marta kirishimiz kerak. O'rnatib bo'lgach, kirish huquqini bemalol qaytarib olishingiz mumkin — bizga doimiy kirish kerak emas.

  1. Serverning IP manzili.
  2. Kirish usuli: SSH kaliti (ma'qulroq) yoki root parol.
Agar serverda boshqa loyihalar ishlayotgan bo'lsa, buni oldindan ayting. Biz ularga tegmaymiz, lekin bilib turishimiz kerak — 1-qadamdagi tekshiruv aynan shuni ham aniqlaydi.

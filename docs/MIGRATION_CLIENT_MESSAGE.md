# Mijozga yuboriladigan xabar (tayyor matn — nusxa oling va jo'nating)

_Yozilgan 2026-08-07. Maqsad: mijoz to'rtta narsani ochsin, qolganini biz qilamiz._
_Batafsil texnik ro'yxat: `MIGRATION_REQUIREMENTS.md`. Bu fayl faqat jo'natiladigan matn._

---

Assalomu alaykum.

Ilovani sizning o'z hisobingizga ko'chirishga tayyormiz. Buning uchun **to'rtta narsa** kerak — hammasi sizning nomingizda ochiladi, ya'ni tizim to'liq sizniki bo'ladi. Har biri 5–10 daqiqalik ish.

**1. Railway'da hisob va bitta loyiha**
railway.com → ro'yxatdan o'ting → "New Project".
Ilova shu yerda ishlaydi.

**2. O'sha loyihaga MySQL baza qo'shish**
Loyiha ichida "+ New" → "Database" → "MySQL".
Boshqa hech narsa sozlamaysiz — Railway o'zi ulaydi.

**3. Cloudflare R2'da video ombori**
cloudflare.com → R2 bo'limi → `ustoz-videos` nomli "bucket" oching.
So'ng "API token" yarating — undan **ikkita kalit** chiqadi (biri "access", biri "secret"). Ikkalasi ham kerak.

**4. Gemini kaliti (sun'iy intellekt uchun)**
aistudio.google.com/app/apikey → "Create API key".
Shundan keyin AI xarajati sizning hisobingizdan ketadi — hozirgi sarf oyiga taxminan $7.

---

**Bizdan nima:** qolgan 19 ta sozlamani biz to'ldiramiz, barcha yozuvlarni (12 ta, jami 7 soat 40 daqiqa) ko'chiramiz va **har birini bittalab ochib tekshiramiz**. Jamoangiz uchun bitta o'zgarish bo'ladi: brauzer kengaytmasini bir marta qayta o'rnatish kerak.

**Kafolat:** eski serverdagi hech narsa o'chirilmaydi — yangi joyda hamma yozuv ochilayotgani isbotlanmaguncha. O'chirish kerak bo'lganda alohida so'raymiz.

**Bitta ogohlantirish, oldindan aytamiz:** hozirgi server oyiga qat'iy summa oladi. Railway esa ishlatilganiga qarab hisoblaydi, ilova esa video qayta ishlash bilan shug'ullanadi. Ya'ni hisob arzonroq ham, qimmatroq ham chiqishi mumkin — birinchi oy hisobni birga kuzatamiz.

Kalitlarni tayyor bo'lganda yuboring — xavfsiz tarzda, oddiy xabarda emas.

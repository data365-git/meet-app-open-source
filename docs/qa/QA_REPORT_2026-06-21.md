## Findings

### Finding #1 — Dashboard mobile horizontal overflow — FIXED
At 375px the sticky bottom mobile tab bar (`MobileTab.tsx`) overflowed the viewport by
~22px → horizontal scrollbar. Root cause: outer row used `gap-10` with `justify-between`
(the gap can only force overflow, never helps since justify-between already spreads),
and the 3-icon cluster used `gap-6`. Fix: `gap-10`→`gap-4`, `gap-6`→`gap-3`. Mobile-only
(`lg:hidden`) → desktop unaffected. Verified live: scrollWidth 375 == clientWidth 375.
Commit `c7800ce`. Root typecheck + biome green.

### Finding #2 — Corrupt recording mp4 (informational, NOT a web-app bug)
Triggering AI generation on recording `namtwrasq9g90k4` failed at transcription:
`ffmpeg could not read video file: no streams detected` (fragmented MP4 missing
trex/tfhd boxes). The transcription pipeline detected it and correctly marked the video
ERROR with a clear message + retry — good error handling. The fault is the **source
file** (a malformed extension recording), not the web app. Relevant to Chrome-extension
recording reliability (owner-physical/extension territory), tracked separately. The
golden test video proves the full happy path works end-to-end.
